# Approved Acadia branding

These files are the approved Acadia artwork. Both are 1254 × 1254 PNGs with 8-bit RGBA color.

| File | Use |
| --- | --- |
| `acadia-logo.png` | Full Acadia logo artwork, including the name, for application branding. |
| `acadia-icon.png` | Three-part mark on a rounded dark tile, used as the desktop application icon source. |

Electron Builder derives the platform icon files automatically from `acadia-icon.png` during packaging. Keep these approved PNG originals unchanged; generated platform icons are build outputs.
