# Upstream license supplements

These are unmodified upstream license texts for components whose published npm packages omit the complete license file. `scripts/third-party-notices.cjs` incorporates them into the shipped `docs/THIRD-PARTY-NOTICES.txt`; notice generation requires no network access.

| File                      | Component and provenance                                                                                                                                                                                                                                                                                           |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `saxes-6.0.0-LICENSE.txt` | Complete license and inherited attribution from [saxes v6.0.0](https://github.com/lddubeau/saxes/blob/v6.0.0/LICENSE), matching the installed dependency.                                                                                                                                                          |
| `tr46-MIT.txt`            | MIT license with the original Sebastian Mayr attribution from [upstream tr46 commit 7f1eb920768c794be40962a4f0cbad670a398d04](https://github.com/jsdom/tr46/blob/7f1eb920768c794be40962a4f0cbad670a398d04/LICENSE.md). The older `tr46@0.0.3` package declares MIT and the same author but omits the license file. |
| `tessdata-APACHE-2.0.txt` | English `.traineddata` files distributed in `@tesseract.js-data/eng@1.0.0`; [naptha/tessdata LICENSE at commit 806cd9adc8c6e8abc11c782db1818c990576bebc](https://github.com/naptha/tessdata/blob/806cd9adc8c6e8abc11c782db1818c990576bebc/LICENSE).                                                                |
| `skia-BSD.txt`            | Skia license at [commit 1fdbea293a53b270e3f5e74c92cc6670d68412ff](https://github.com/google/skia/blob/1fdbea293a53b270e3f5e74c92cc6670d68412ff/LICENSE), the Skia submodule pinned by [native canvas v0.1.80](https://github.com/Brooooooklyn/canvas/tree/v0.1.80).                                                |

The OCR npm wrapper declares `MIT` in its package metadata. Its upstream data repository identifies the distributed training data under Apache-2.0 and documents the `4.0.0` and `4.0.0_best_int` data included in those npm packages. The generated notices retain that distinction rather than treating the model data as covered by the wrapper metadata alone.

Other missing root-level license files are recovered from the installed package's own README (`hash.js` and `isarray`), or the same-version parent canvas package's MIT license for platform-specific binaries. The generator also includes nested PDF.js licenses for fonts, color profiles, and codecs. Review these mappings when upgrading dependencies; an unknown missing license stops generation.
