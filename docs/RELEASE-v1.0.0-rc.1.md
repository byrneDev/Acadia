# Acadia 1.0.0-rc.1 — Research-to-delivery qualification candidate

This candidate completes dependable daily-work features while preserving Acadia's local Collector and released Releaser boundary. It is not the final qualified 1.0 release.

- Checked library backups and recovery that preserve the replaced workspace, including startup failure recovery.
- Recoverable private research drafts, explicit save states and persistent keyboard board movement.
- Complete paged search, manually inserted historical passage citations and original PDF page comparison.
- Optional fictional software and curriculum practice investigations without AI.
- Pin-independent retrieval, gap/decision change tracking and updated research appendices.
- Delivery work packages linked to historical gaps/findings, requirements or learning objectives, acceptance tests and verification evidence.
- Expanded Power BI records, PMIS mapping information and bibliography metadata.
- Explicit synthetic model generation testing, saved credential removal, bounded model work, redacted diagnostics and manual update checks.
- Portable format v5, import compatibility with v1–v4, and background archive compression.

Back up important work before trying this candidate. New v5 exports require the 1.0 candidate or later. Keep previous installers and independent research backups; do not open a migrated database with an older binary.

See [candidate validation](VALIDATION-v1.0.md), [recovery](RECOVERY.md), and [PMIS handoff](PMIS-HANDOFF.md). Signing/notarization, live destination imports, physical devices, assistive technologies, and independent testers are explicit qualification gates. Candidate automated tests cannot substitute for them. No unsupported model or research-accuracy claim is made.
